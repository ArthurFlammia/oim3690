## Code I want to highlight
The hand-written HTML skeleton I started `hello.html` with, before enhancing it:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <title>Hello!</title>
</head>
<body>
  <h1>Hello, world!</h1>
</body>
</html>
```

This is the minimum structure every HTML page needs: a doctype line, the `<html>` wrapper, a `<head>` for page info like the title, and a `<body>` for the content you actually see.
