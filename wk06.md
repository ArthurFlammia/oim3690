## Code I want to highlight
```js
function calculateTip() {
  const bill = Number(document.getElementById("bill").value);
  const tipPercent = Number(document.getElementById("tip").value);
  const people = Number(document.getElementById("people").value);

  const tipAmount = bill * (tipPercent / 100);
  const total = bill + tipAmount;
  const perPerson = total / people;

  resultsBox.innerHTML =
    "Each person pays: $" + perPerson.toFixed(2);
}
```
This reads the three numbers the user types, does the tip math, and shows what
each person owes. I can explain every line: `Number()` converts the input text
into a number so the math works, and `toFixed(2)` rounds to two decimal places.

## AI usage this week
I used AI to generate the starter HTML, CSS, and JavaScript for the tip splitter
based on a description of the problem I wanted to solve. One of the biggest things
I learned was why input values need to be wrapped in Number(). Values entered in
form fields are treated as text by default, so without converting them, JavaScript
would combine the values as strings instead of performing mathematical
calculations. I also asked AI to explain toFixed(2), which rounds numbers to two
decimal places so the results display neatly instead of showing long decimal
values.

## One question I still have
