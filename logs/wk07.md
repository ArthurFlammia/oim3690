## Code I want to highlight
```javascript
history.push({
  id: nextId,
  bill: bill,
  people: people,
  total: total,
  each: each,
});
nextId = nextId + 1;
```
The `history` array stores every bill split that the user calculates during the session. Each split is saved as an object with its own unique `id` so that individual entries can be removed later if needed. Both the saved-splits list displayed on the page and the running session total are built from this array, which makes it the main place where all of the app's data is stored.
