## Code I want to highlight
```javascript
try {
  const place = await geocodeCity(name);
  if (place === null) {
    setStatus("Couldn't find that city. Check the spelling and try again.");
    return;
  }
  const weather = await fetchForecast(place.latitude, place.longitude);
  renderCurrent(place, weather.current);
  renderForecast(weather.daily);
} catch (error) {
  setStatus("Something went wrong. Check your connection and try again.");
} finally {
  searchBtn.disabled = false;
}
```
This section handles the application's search process. First, `await geocodeCity(name)` converts the city name into latitude and longitude coordinates. Once those coordinates are returned, `fetchForecast()` retrieves the weather data for that location. Because the forecast depends on the coordinates, these steps must happen in order.

The `catch` block displays a user-friendly error message if something goes wrong instead of allowing the application to fail silently. The `finally` block always re-enables the Search button, regardless of whether the request succeeds or fails.
