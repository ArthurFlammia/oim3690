## Code I want to highlight
```js
const bgColors = ["#ffadad", "#ffd6a5", "#fdffb6", "#caffbf", "#9bf6ff", "#a0c4ff"];
const randomIndex = Math.floor(Math.random() * bgColors.length);
document.querySelector("body").style.backgroundColor = bgColors[randomIndex];
```
This picks a random color from the array and sets it as the page background.
`Math.random()` gives a decimal from 0 up to (but not including) 1, multiplying by
the array length stretches that across all the slots, and `Math.floor()` rounds
down to a whole number so it's always a valid index.

## AI usage this week
I asked AI to explain the difference between using addEventListener() in
JavaScript and using onclick="" directly in the HTML. I learned that both can
respond to a button click, but addEventListener() keeps the JavaScript separate
from the HTML and allows multiple actions to be attached to the same event.
Keeping the code separate makes it easier to organize and maintain as projects get
larger.
