## Code I want to highlight
```javascript
// TheMealDB stores ingredients in 20 numbered fields
// (strIngredient1..20 + strMeasure1..20), so we loop and collect the non-empty ones.
let ingredientItems = "";
for (let i = 1; i <= 20; i++) {
  const ing = apiMeal["strIngredient" + i];
  const measure = apiMeal["strMeasure" + i];
  if (ing && ing.trim() !== "") {
    ingredientItems +=
      "<li>" + ing + " <span>— " + (measure || "").trim() + "</span></li>";
  }
}
```
This is from `renderDetail()`. TheMealDB doesn't return ingredients as an array,
which is what I expected. It returns twenty separate flat fields named
`strIngredient1` through `strIngredient20`, plus a matching `strMeasure1` through
`strMeasure20`, and most of them are empty on any given recipe.

The loop rebuilds the field name as a string each time — `"strIngredient" + i`
gives `"strIngredient1"`, then `"strIngredient2"`, and so on — and looks it up with
bracket notation. Dot notation wouldn't work here because the key isn't known until
the loop runs.

The `if (ing && ing.trim() !== "")` check is what keeps the list clean. A recipe
with 8 ingredients still has 20 slots; the other 12 come back as `null` or `""`,
and without that check the page renders a dozen blank bullet points. That's exactly
the bug I hit before adding it.
