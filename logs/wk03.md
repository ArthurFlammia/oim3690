## Code I want to highlight

```css
/* CLASS SELECTOR
   Reused on links I want to look like buttons. */
.button-link {
  display: inline-block;            /* lets padding/margins work like a box */
  background-color: rgb(0, 102, 51); /* green background */
  color: rgb(255, 255, 255);        /* white text */
  padding: 8px 16px;                /* vertical, horizontal padding */
  text-decoration: none;            /* remove the default underline */
}

/* :HOVER PSEUDO-CLASS
   Applies only while the mouse is over a .button-link.
   This is a state, not a separate element. */
.button-link:hover {
  background-color: rgb(0, 153, 76); /* lighter green on hover */
}
```
