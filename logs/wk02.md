## Code I want to highlight
A section of `about-me.html` I can explain:

```html
<section>
  <h2>A few quick facts</h2>
  <ul>
    <li>I'm studying business at Babson.</li>
  </ul>
</section>
```

`<section>` groups related content together, `<h2>` is a sub-heading, and `<ul>`
with `<li>` items makes a bulleted list. The external stylesheet link and the
`id="intro"` on the section above this one came from class, not from a prompt.

## AI usage this week
This is the week I settled into a pattern I've used since: generate, then annotate.
I hand-wrote the bare skeleton of `hello.html` myself — doctype, html, head, title,
body, and one `<h1>` — and then asked AI to enhance it. It came back with a
paragraph, a list of the tags I'd learned so far, and some styling.

Instead of taking it at face value, I went through the whole file and added
comments marking what each part does, on the theory that if I couldn't write the
comment I didn't actually understand the line. That's where I learned `&lt;` and
`&gt;` are HTML entities — they're how you print literal angle brackets instead of
having the browser read them as a tag. The comment block explaining all of this is
still at the top of the file.
