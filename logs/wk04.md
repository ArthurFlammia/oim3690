# Week 04 Learning Log

## What I worked on this week

This week I built out my MP1 client site for Platinum Pools — a multi-page static
site (home, services, contact) with an external stylesheet. I used Flexbox for the
layout: the header lays the site name and nav out in a row, and the services
section uses a flex row so the three cards sit at equal width, then stacks them on
small screens with a media query.

## Code I want to highlight

```css
/* flexbox lines the three cards up in a row */
.card-row {
  display: flex;
  gap: 16px;            /* space between cards */
}

.card {
  flex: 1;              /* each card takes equal width */
  background-color: #ffffff;
  border: 1px solid #ddd;
  border-radius: 4px;
  padding: 20px;
}
```

## AI usage this week

For the Platinum Pools project, I used AI to generate a stylesheet that utilized
Flexbox for the service cards and included a media query to stack them on smaller
screens. After showing the site to my client, Vernon, he felt the design looked
too simple and requested additional photos. I then expanded the services page by
adding an image gallery and adjusted the color scheme from the AI-generated
version to better match the company’s branding and preferences.
